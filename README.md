# 고모 편집실 · GOMO Studio v0.3

**고모 창작실에서 만든 작품에 목소리를 입혀 MP4 영상으로 완성하는 Windows 데스크톱 앱.**
고모 창작실(knhanul/Creator)과 한 세트이며, 화면 구성·디자인 토큰·테마를 창작실과 같게 맞췄습니다.

- Electron + React + TypeScript (electron-vite)
- 녹음: 앱 안에서 바로(마이크 → WAV). **Python 필요 없음**
- 영상 만들기: 함께 설치되는 FFmpeg(`ffmpeg-static`). **Python 필요 없음**
- 예전 Python 엔진(knhanul/dubbing) 연결은 `환경 설정 → 고급`에 선택 사항으로 남겨 두었습니다.

## 빠른 시작 (Windows)

요구 사항: Windows 10/11, Node.js 22.12 이상, 마이크.

```powershell
git pull
npm install      # FFmpeg(ffmpeg-static)도 이때 함께 내려받습니다
npm run dev
```

또는 `START_WINDOWS.bat` 더블클릭.

1. **창작실 작품 불러오기** → 창작실 「더빙 전달」로 내보낸 폴더 선택 (폴더를 창에 끌어다 놓아도 됨)
2. **장면 구성** → 순서·길이·움직임·전환 확인, **미디어 보관함**에서 장면마다 이미지/영상/다른 버전 고르기
3. **더빙 녹음** → 마이크 고르고, 3·2·1 뒤에 문장별 녹음
4. **자막 다듬기** → 문구·시간·모양
5. **배경음악** → 음악과 목소리 크기, 자동 줄이기, 장면마다 음악 바꾸기·효과음
6. **영상 내보내기** → 미리보기(빠르게) 또는 완성 영상 MP4

## v0.3.1 — 장면 전환 깜박임 없애기 (창작실 효과 규격 gomo.effects.v1)

- 같은 장면(scene_id)·같은 그림의 연속 샷을 **한 구간**으로 묶어 렌더링 — 샷 사이에는 섞지 않고 카메라(배율·중심)가
  앞 샷이 끝난 자리에서 이어 움직임(속도까지 이어지게 단조 3차 보간, 구간 처음·끝만 ease-in-out)
- motion 10종(static · zoom_in/out · pan_left/right/up/down · focus_in/out · drift) + 예전 움직임 그대로
- 구간 사이만 xfade로 섞음. 창작실 `fade`는 서서히 섞기(예전 편집실 프로젝트의 `fade`만 검은 화면 페이드),
  `dissolve`는 점으로 반짝이는 xfade dissolve 대신 서서히 섞기, fadeblack·fadewhite는 지정한 곳에서만
- 영상 장면: 기준 이미지 정지 샷 → 영상 샷 사이는 0.3~0.5초 서서히 섞기, 영상 앞 검은 프레임(최대 0.5초) 자동 잘라 냄
- 모든 시각을 프레임 단위로: 구간 프레임 수 = round(길이×fps), xfade offset = 구간 시작 프레임 ÷ fps,
  다음 구간과 섞이는 시간만큼 앞 구간을 늘려 그려 전체 길이·자막 시각은 그대로
- 색감(tone 8종)은 구간마다 xfade 전에 적용, 분위기 효과는 vignette만 우선 지원(나머지는 렌더 로그·완료 메시지에 기록)
- 편집 화면 미리보기도 같은 구간·카메라·전환 규칙(`shared/camera.ts`)을 씀, 다음 구간을 미리 올려 두어 영상 첫 프레임 깜박임 없음
- `node scripts/boundary-check.mjs` — 테스트 프로젝트를 렌더링하고 클립 경계 ±0.5초 프레임의 밝기·차이·크기·pts를 검사

## v0.3 — 창작실의 다양한 미디어 그대로 쓰기

창작실 제작 패키지는 장면마다 **이미지와 영상(이미지→동영상의 기준 이미지)**, 다시 만든 **버전(`S04_image_v2.png`)**,
**여러 배경음악(`BGM_01.mp3`, `BGM_02.mp3` …)** 을 함께 담아 보냅니다. 편집실은 이걸 모두 읽어 골라 쓰게 합니다.

**미디어 보관함** (장면 구성 · 배경음악 화면의 `미디어 보관함` 버튼)
- 창작실 `project.json`(creator.project.v1)을 읽어 모든 미디어를 장면별로 묶어 보여 줌
  (장면에 연결 · 기준 이미지 · 다른 버전 v2 · 배경음악 · 추가 파일, 어디에 쓰고 있는지 표시)
- 파일 이름 규칙(`S04_image.png` · `S04_video.mp4` · `BGM_01.mp3`)으로 나중에 넣은 파일도 장면에 자동 연결 → `폴더 다시 읽기`
- 이미지·영상: 선택한 장면 바꾸기 / 새 장면으로 넣기 · 음악: 배경음악 / 그 장면부터 이 음악 / 효과음 · 들어 보기

**장면 구성**
- 오른쪽 패널 `같은 장면의 다른 미디어`: 이미지 ↔ 영상, 다른 버전으로 한 번에 바꾸기 (보이는 길이는 그대로)
- 영상 장면의 **기준 이미지**를 썸네일·미리보기 포스터로 사용, 영상 파일이 없으면 기준 이미지로 대신 보여 줌
- `기준 이미지를 앞에 넣기 (이미지 → 영상)`: 같은 그림의 정지 화면으로 시작해 영상으로 서서히 바뀌는 연출
- `composer_project.json`이 없는(미디어가 덜 연결된) 패키지도 `project.json`으로 바로 열기:
  영상이 아직 없는 영상 장면은 기준 이미지로, 연결 안 된 장면은 같은 장면 이름의 파일로 채움

**배경음악 · 소리**
- 패키지 음악(BGM_01, BGM_02 …)을 칩으로 바로 고르기
- **장면마다 음악 바꾸기**: 고른 장면부터 다른 음악 — 앞 음악은 그 시각에 서서히 끝나고 새 음악이 이어짐
- **효과음**: 재생 위치에 소리 넣기, 시작·끝·크기·반복·페이드·목소리 나올 때 줄이기 따로 조절
- 타임라인에 바뀌는 음악·효과음 줄 표시, 미리듣기와 MP4 렌더 모두 반영 (자동 줄이기는 음악 전체에 함께 적용)

프로젝트 파일에는 `media_library` · `audio_cues` · `clip.scene_id` · `clip.poster` · `bgm.end`가 편집실 확장으로 저장됩니다
(Video Composer v2 기본 항목은 그대로라 예전 영상 합성기에서도 열림 — 확장 소리는 편집실 렌더에서만 반영).

## v0.2 기능

**창작실 작품 불러오기**
- `composer_project.json`(우선) 또는 `gomo-handoff.json`(creator.handoff.v1)을 자동 변환
- 자막이 비어 있으면 `captions.srt`를 읽음, 영상 길이는 FFmpeg로 확인
- 폴더 끌어다 놓기, 최근 작업 목록, 900ms 자동 저장, 실행 취소 60단계

**장면 구성**
- 이미지/영상 바꾸기, 끌어서 순서 바꾸기, 보여 줄 시간, 영상 속도·앞부분 자르기·원래 소리
- 화면 움직임(천천히 확대/축소, 좌우·상하 흐르기, 켄 번스) + 세기, 모든 장면에 적용
- 전환: 바로 전환 / 서서히 바뀜 / 검은 화면 페이드 + 시간

**더빙 녹음**
- 마이크 고르기, 입력 레벨 표시, 3·2·1 카운트다운
- 지금 읽을 문장을 크게, 다음 문장 미리 보기, 해당 장면 썸네일
- 문장별 녹음 → `takes/line_0001_v1.wav` … (다시 녹음해도 이전 파일은 지우지 않음)
- 듣기·다시 녹음·지우기·크기·앞뒤 자르기(무음 자동 자르기), 음성 파일 불러오기
- "저장하고 다음 문장"(N), 녹음 길이에 장면·자막 자동 맞추기
- 단축키: R 녹음/정지 · N 다음 문장 · Esc 취소

**자막 다듬기**
- 문구·시작/끝 시간, ±0.1초 미세 조정, 재생 위치로 시작/끝 지정, 녹음에 맞추기
- SRT 불러오기/저장, 영상에 새기기 켜기/끄기, 위치·크기·색·외곽선·굵게·배경 상자·전체 시간 이동

**배경음악**
- 음악 파일, 목소리/배경음악/원본 영상 소리 크기
- 목소리 나올 때 자동 줄이기(조금/보통/많이), 처음·끝 페이드, 반복 재생

**타임라인** — 장면·더빙·자막·배경음악(+효과음) 줄, 확대/축소, 눌러서 이동

**영상 내보내기**
- FFmpeg MP4(H.264 + AAC), 진행률·취소, 완성 후 바로 재생 / 폴더에서 보기
- 미리보기(작은 화면, 빠르게) / 완성 영상, 화면 크기 프리셋, fps, 파일 이름, 처음·끝 페이드
- 렌더 방식은 dubbing의 `ffmpeg_builder.py`를 따름: 장면별 중간 파일 → xfade 이어 붙이기 → ASS 자막 → 목소리·배경음악(sidechain 자동 줄이기) 믹스

## 일부러 뺀 기능 (나중에 천천히)

Whisper 자동 자막/정렬, 색감·필터·효과 UI, 녹음 여러 버전 고르기, 3가지 외 전환 효과, 영상 클립 움직임,
NVENC 하드웨어 인코딩, 트랙 잠금/솔로, 타임라인 핸들 끌어서 자르기, 자막 트랙 별도 첨부(soft sub), AI 편집안.

## 프로젝트 형식

Video Composer `version: 2` JSON(dubbing과 같은 형식). 상대 경로는 프로젝트 JSON 폴더 기준.
- 창작실 미디어: `assets/image|video|audio/`, 가져온 미디어: `media/`, 녹음: `takes/`, 미리보기: `preview_gomo.mp4`, 완성: `output.file`

## Windows 참고

- **마이크:** Windows 설정 → 개인 정보 → 마이크 → "데스크톱 앱이 마이크에 액세스하도록 허용" 켜기.
- **FFmpeg:** `npm install` 때 함께 받습니다. 회사망 등으로 실패하면 `환경 설정 → FFmpeg`에서 ffmpeg.exe를 직접 지정.
- **자막 글꼴:** 기본 `Malgun Gothic`(C:\Windows\Fonts)을 사용합니다.

## 보안·브랜드

- `nodeIntegration:false`, `contextIsolation:true`, preload API만 사용. `gomo-media://`는 허용된 파일만 읽음.
- 마이크 권한은 앱 창 안에서만 허용. 외부 포트를 열지 않음.
- 표시 이름은 `src/shared/brand.ts`. appId·저장 경로는 이전 설치와 호환되도록 그대로 둠.
