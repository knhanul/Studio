# Windows 실환경 체크리스트

- [ ] `npm run typecheck` / `npm run test` / `npm run build` 통과
- [ ] 고모 창작실 출력 `composer_project.json` 열림
- [ ] 기존 Video Composer v2 프로젝트 열림 (기존 효과·추가 필드 유지)
- [ ] 한글 경로·긴 경로·특수문자 파일명 정상
- [ ] 클립 추가·순서 이동·길이 수정·저장·재열기 유지
- [ ] 원본 SRT 파싱·저장·재열기 타임코드 일치
- [ ] Python 엔진 연결·마이크 장치 목록 수신
- [ ] 녹음 WAV 파일 정상·테이크 JSON 반영
- [ ] 미리보기 렌더·취소 정상
- [ ] 최종 MP4 영상·BGM·목소리·자막 정상
- [ ] 원본 PySide6 프로그램에 저장 JSON을 열었을 때 동일 프로젝트
- [ ] 영상 합성 결과가 기존 프로그램과 프레임·오디오 품질 면에서 일치
